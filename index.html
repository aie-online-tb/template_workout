Abre el proyecto en GitHub Codespaces (entorno en la nube con VS Code en el navegador). Pulsa el botón y crea o reutiliza un Codespace del repositorio:

Opción local en VS Code: Fork + Clone del repositorio GitHub

Necesitas tener Python 3 y VS Code instalados (nuestro IDE de referencia en el curso).

Pasos:

  1. Ve al repositorio oficial:
  2. Haz clic en Fork
  3. En tu fork, botón Code → copia la URL HTTPS
  4. En tu terminal local: 
    git clone https://github.com/TU_USUARIO/REPOSITORIO_FORKEADO.git
  5. Haz `pip install` para instalar las dependencias del ejercicio que toque
  6. Abre la carpeta en VS Code local
  7. Trabaja, haz commit y push a tu fork para guardar tus cambios
