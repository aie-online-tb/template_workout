Opción remota: trabaja en una máquina virtual

Antes de empezar, inicia sesión en tu cuenta de GitHub en el navegador

Opción 1: Trabaja online en GitHub Codespaces

Pulsa el botón para abrir el proyecto en GitHub Codespaces (En esta opción, los cambios se guardan en la máquina virtual, pero no en tu repositorio propio de GitHub).

Si ya tienes un Codespace de este repositorio, reutilízalo; no hace falta crear uno nuevo cada vez.

Opción 2: empezar desde GitHub (Fork + Codespaces)

Esta opción te permitirá guardar tus cambios en tu repositorio propio de GitHub

  1. Ve al repositorio oficial:
  2. Haz clic en Fork para hacer una copia del repositorio en tu cuenta de GitHub
  3. En tu fork, botón Code → Open in Codespaces
  4. Comienza a trabajar. Haz add, commit y push a tu fork para guardar tus cambios

Opción local en VS Code: Fork + Clone del repositorio GitHub

Necesitas tener Python 3 y VS Code instalados (nuestro IDE de referencia en el curso).

Pasos:

  1. Ve al repositorio oficial:
  2. Haz clic en Fork
  3. En tu fork, botón Code → copia la URL HTTPS
  4. En tu terminal local clona tu fork: 
    git clone https://github.com/TU_USUARIO/REPOSITORIO_FORKEADO.git
  5. Haz pip install para instalar las dependencias del ejercicio que toque
  6. Abre la carpeta en VS Code local
  7. Comienza a trabajar. Haz add, commit y push a tu fork para guardar tus cambios

Alternativa: trabajar en local con VS Code

Si prefieres trabajar en tu ordenador en lugar de en la nube, puedes hacerlo localmente.

Opción local

  1. Clona el repositorio de clase: 
    git clone https://github.com/OWNER/REPO.git
  2. Copia los notebooks (.ipynb) a tu repositorio personal
  3. Abre los notebooks en VS Code (con la extensión Jupyter instalada)
  4. Trabaja como lo harías en Colab, pero en tu ordenador
